## Key Issues Resolved

### 1. Python Environment & Package Installation
**Problem:** Packages installed in another venv couldn't be imported in current project.

**Solution:** 
- Verified that venvs are isolated - packages don't transfer between them
- Checked current venv packages with `get_python_environment_details`
- Confirmed all required packages were already installed:
  - sentence-transformers (3.3.1)
  - numpy (2.3.5)
  - torch (2.9.1+cpu)
  - plotly (6.5.0)
  - scikit-learn (1.8.0)
  - umap-learn (0.5.9.post2)
  - google-genai (1.56.0)

### 2. Gemini API Quota Exhaustion
**Problem:** Gemini API returned 429 RESOURCE_EXHAUSTED errors - free tier quota exceeded.

**Solution:** 
- Implemented multiple AI backend support (Ollama, Gemini, HuggingFace)
- Recommended **Ollama** as primary solution:
  - 100% free and unlimited
  - Runs locally on PC
  - No API keys needed
  - Works offline
  - No quotas or rate limits

**Installation:**
```powershell
winget install Ollama.Ollama
ollama pull llama3.2
```

### 3. Graph Auto-Refresh Without Flashing
**Problem:** Initial implementation used meta refresh tag causing black screen flashing every 2 seconds.

**Solutions Attempted:**
1. **First attempt:** JavaScript fetch with Plotly.react() - had CORS/file loading issues
2. **Final solution:** Embedded data directly in HTML with page reload
   - Data embedded as JSON in HTML file
   - Page reloads every 3 seconds (cleaner than meta refresh)
   - Auto-refresh disabled when conversation ends

### 4. Continuous Refresh After Quit
**Problem:** Graph continued refreshing even after user quit the conversation.

**Solution:**
- Added `is_final` parameter to `create_interactive_plot()`
- When user quits or presses Ctrl+C:
  - Final graph generated with `is_final=True`
  - Auto-refresh script disabled
  - Status changes from "🟢 Live" to "🔴 Stopped"
  - Display shows "No refresh" instead of "Auto-refresh: 3s"

## Technical Concepts Clarified

### Desktop Application vs Library Wrapper
**Desktop Application (Ollama):**
- Complete standalone program
- Runs as background service
- Includes server + CLI + models
- System-wide installation

**Library Wrapper (pip install ollama):**
- Optional Python helper package
- Just wraps HTTP requests in convenient functions
- **Not needed** - code uses `requests` directly

### Software Components
- **Server:** Background process listening on http://localhost:11434
- **CLI:** Command-line tools (ollama pull, run, list)
- **Main Application:** Complete package including both

### Installation Locations
- **Ollama:** `C:\Users\<User>\AppData\Local\Programs\Ollama\`
- **Models:** `C:\Users\<User>\.ollama\models\`
- **Python packages:** `AI-dialogue-project\.venv\Lib\site-packages\`

## Lessons Learned

1. **Virtual environments are isolated** - packages don't transfer between venvs
2. **API quotas matter** - free tiers have limits, local models are unlimited
3. **Page refresh vs AJAX** - Sometimes simple reload is more reliable than complex AJAX
4. **Pre-warming improves UX** - Loading model once upfront prevents slow first response
5. **Incremental updates** - Only embedding new data is much faster than re-embedding everything
6. **Embedding data in HTML** - Avoids CORS and file path issues
